# Caderno Temático: Linguagens de Programação — NotebookLM
 
> Este repositório documenta a criação de um caderno temático no NotebookLM sobre linguagens de programação, desenvolvido como parte do **Bootcamp Afya - Automação de Dados com IA**.
 
---
 
## Contexto
 
Este projeto foi desenvolvido como parte do desafio x do **Bootcamp  Afya - Automação de Dados com IA**. O O NotebookLM é uma ferramenta que permite criar um caderno de estudos inteligentes, capaz de responder perguntas, gerar resumos, criar áudios, vídeos e apresentações explicativas com base nas fontes que você mesmo fornece.
 
O tema escolhido foi **linguagens de programação**, por ser um assunto fundamental na área de desenvolvimento e com amplo material técnico disponível para alimentar o caderno.
 
---
 
## Objetivos
 
- Apresentar o conceito de linguagens de programação e seu papel no desenvolvimento de software.
- Explicar e comparar os principais paradigmas (orientado a objetos, funcional, procedural, lógico).
- Relacionar linguagens reais com aplicações e serviços conhecidos.
- Demonstrar exemplos práticos de código para ilustrar diferenças entre linguagens.
